# Simple FAQ Chatbot using Python

## Project Name

Simple FAQ Chatbot using Python

## Goal

Create a chatbot that answers common questions automatically.

## Workflow

1. User asks question
2. Chatbot checks FAQ data
3. Finds matching question
4. Gives answer

## Tools Required

- Python
- VS Code / PyCharm
- Basic Dictionary
- If-Else
- Loop
- String Matching

## Features

- FAQ data stored in dictionary
- Takes user input
- Converts input into lowercase
- Checks question in FAQ dictionary
- Gives answer if question is found
- Displays a message if answer is not found
- `exit` command to stop the chatbot

## How to Run

```bash
python chatbot.py
